# GISARA — Risk Register

Status legend: **CLOSED** (fixed + verified), **OPEN** (confirmed, not fixed), **WATCH** (safe today, fragile).
Evidence for every CLOSED item is a passing run of `scripts/smoke-test-payments.sh` or `scripts/smoke-test-security.sh`, plus `tsc --noEmit` and `vite build`.
